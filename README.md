# Leonida Field Guide

An unofficial, spoiler-safe second-screen companion for Grand Theft Auto VI.

Not affiliated with or endorsed by Rockstar Games or Take-Two Interactive.

## Run it

Needs Node 22 or newer.

```sh
npm ci
npm run dev      # local site
npm run check    # type check, then a full build that validates every answer record
```

The contract is `docs/spec.md`. Rules for agents are in `AGENTS.md`.
